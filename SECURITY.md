# Security and research-data policy

Please report security issues privately to the repository owner rather than opening a
public issue. Replace this text with a monitored contact address before publication.

This repository contains no CPWV or UPV/EHU research data. Contributors must not upload
restricted simulation cases, unpublished experimental measurements, credentials, cluster
paths, or metadata that can identify protected research assets. Use the synthetic dataset
for public examples and publish real data only when its license and release authority are
documented.
