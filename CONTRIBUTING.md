# Contributing

Thank you for considering a contribution.

1. Open an issue describing the proposed change.
2. Create a focused branch and keep changes small.
3. Add or update tests for behavior changes.
4. Run `ruff check src tests` and `pytest` locally.
5. Do not commit unpublished, restricted, or personally identifiable research data.

Bug reports should include the operating system, Python version, configuration file,
minimal reproduction steps, and the complete error message.
